# Neuroglancer (Fork)

This repository is a fork of the official [google/neuroglancer](https://github.com/google/neuroglancer) project.

It was created to submit a Pull Request to the Google engineering team to fix a Path Traversal vulnerability that allowed arbitrary reading of secrets and system files.

Link to the Pull Request:
https://github.com/google/neuroglancer/pull/915
